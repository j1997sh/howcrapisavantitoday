THE FINE PRINT

About this project

An independent, satirical project. Not affiliated with or endorsed by Avanti West Coast.

Source: The public Avanti live train status page is checked for availability. Its contents are not currently used to calculate train performance.

Methodology: No Crap Score is shown until a representative service-level dataset can establish scheduled, cancelled and delayed services. Missing data is not zero disruption.

Refresh: GitHub Actions attempts a source check every 15 minutes; the browser checks the published snapshot every two minutes. Scheduled runs may be delayed.
